## Какво не е готово и защо?
Потвърдено е публичното [хранилище](https://github.com/Kosio28/GeoQuest-Bulgaria). На 09.11.2026 г. локалният проект беше без commits, а при проверката в GitHub не бяха намерени Issues. Материалите са възстановени от ZIP в работната папка. В GitHub има [начален commit от Kosio28](https://github.com/Kosio28/GeoQuest-Bulgaria/commit/19342f9807981d7e710efd4c1a28bf94af3a47b4) с README, който съдържа само заглавие. Локалният клон е свързан с тази история. GitHub Project и доказателствата за личен принос и на двамата още не са потвърдени. Няма работеща игра, карта, избрани лицензирани снимки, проверена банка с координати или Supabase база. Те са планирани за следващите етапи; за етап 1 работещ код не е задължителен.
[Страница със задачи](https://github.com/Kosio28/GeoQuest-Bulgaria/issues). След работа добавете линк към GitHub Project и към личните commits.
