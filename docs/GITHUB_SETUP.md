# GitHub — стъпки за двамата
Нужни са два отделни профила. Не използвайте един общ акаунт и не споделяйте пароли.

1. Профилът `Kosio28` е потвърден чрез връзката с GitHub. Илиан използва собствен профил и дава потребителското си име на Константин.
2. Отворете [GeoQuest-Bulgaria](https://github.com/Kosio28/GeoQuest-Bulgaria). Хранилището вече съществува и е публично. Проверете указанията на учителя за видимостта преди качване.
3. Собственикът отваря Settings → Collaborators → Add people и кани другия по GitHub потребителско име. Другият приема поканата от своя профил.
4. В GitHub отворете Add file → Upload files и качете прегледаните материали от локалната папка `GeoQuest - Miceva`, като запазите подпапките. Добавете `.gitignore` и `.env.example`, ако интерфейсът ги пропусне. Изключете `.git`, локални тайни и по-ранните Word копия.
5. Първо прочетете и поправете материалите. Константин може да качи/редактира RESEARCH.md и SCREENS.md с commit съобщение „Преглед на проучването и началния дизайн“. Илиан от собствения профил редактира проверената от него част в PROJECT_PLAN.md/SCHEMA_PLAN.md и прави отделен commit „Преглед на адаптацията, разстоянията и модела“. Съобщенията трябва да съответстват на реалната работа.
6. За промяна през браузъра отворете файла, изберете Edit (молив), редактирайте и Commit changes. Един общ commit не покрива изискването за собствен commit от всеки. Запазете URL адреса на всеки реален commit.
7. В Issues създайте 12 задачи с текстовете от GITHUB_ISSUES.md. Задайте Assignees: профила на Константин за неговите шест и профила на Илиан за другите шест.
8. От Projects създайте Project за проекта с Board и статуси Todo, In progress, Done. Добавете 12-те Issues. Ако менюто не се вижда в хранилището, отворете Projects от профила на собственика и свържете проекта с хранилището. Менютата могат да се различават.
9. Всеки попълва своя раздел в WEEK_1_REPORT.md и AI_USAGE.md с действителни действия. Добавете адреса на хранилището и Project в README.md/отчета.
10. Проверете, че учителят може да отвори линковете и изображенията. Предайте хранилище, страницата /issues, Project и документите според Classroom.

Няма нужда от работеща игра или Supabase проект за приключване на етап 1. Не пишете „има демо“, ако още няма.
