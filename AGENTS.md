# Project instructions

## Git commit messages

- Write short, professional commit messages that describe what changed.
- Omit AI attribution and references to AI assistance, including `(Codex-assisted)`, `Co-authored-by: Codex`, and `Generated by AI`. Omit unnecessary trailers.
- Apply these rules to all future commits in this repository, subject to higher-priority requirements. Do not rewrite existing commit history to enforce them.
